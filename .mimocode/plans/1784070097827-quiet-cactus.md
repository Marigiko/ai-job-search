# Plan: Adaptación dual MiMoCode + OpenCode

## Objetivo
Adaptar el proyecto `ai-job-search` para que funcione tanto en MiMoCode como en OpenCode (y mantenga compatibilidad con Claude Code).

## Diagnóstico

**Lo que YA funciona en MiMoCode/OpenCode:**
- Skills en `.claude/skills/*/SKILL.md` (job-application-assistant, job-scraper, upskill)
- Skills en `.agents/skills/*/SKILL.md` (15 portales de búsqueda)
- `CLAUDE.md` como instrucciones globales

**Lo que NO funciona en MiMoCode/OpenCode:**
- Los 10 archivos en `.claude/commands/*.md` son **slash commands** de Claude Code. MiMoCode y OpenCode no descubren `.claude/commands/` como comandos — ellos usan **skills** (archivos `SKILL.md` con frontmatter YAML).

**Diferencia clave:**
- Un *command* usa `$ARGUMENTS` (variable injectada por Claude Code).
- Un *skill* se invoca por nombre (`/apply`) y el modelo lee el contexto del mensaje. No tiene `$ARGUMENTS`.

**Paths de descubrimiento de skills:**
| Platforma | Paths |
|-----------|-------|
| MiMoCode | `.claude/skills/**`, `.agents/skills/**`, `.codex/skills/**`, `.opencode/skills/**` |
| OpenCode | `.opencode/skills/**` (nativo) |
| Claude Code | `.claude/skills/**`, `.claude/commands/**` |

**Estrategia dual:** Cada comando se convierte a skill y se ubica en AMBOS paths: `.claude/skills/<name>/SKILL.md` (MiMoCode + Claude Code) y `.opencode/skills/<name>/SKILL.md` (OpenCode). Las `.claude/commands/*.md` originales se mantienen para retrocompatibilidad con Claude Code.

### 2. Patrón de conversión

Cada `SKILL.md` necesita:

```yaml
---
name: <command-name>
description: >
  [descripción corta con keywords de trigger, compatible con los triggers actuales del command]
allowed-tools: [lista de tools que el command usa]
---
```

Cambios de contenido:
- Eliminar `$ARGUMENTS` — reemplazar por "el URL o texto proporcionado por el usuario" / se lee del contexto del mensaje
- Mantener toda la lógica de steps intacta
- Referenciar skill por nombre sin prefijo `/` cuando se menciona en contexto de skills (ej: "invoke the apply skill" en vez de "/apply")
- El frontmatter `allowed-tools` derivado de las herramientas que cada command referencia
